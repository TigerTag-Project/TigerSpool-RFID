# Report faithfully

**Rule.** Report what was compiled and what was observed on hardware as two separate claims. Ask for a hardware test only for what genuinely needs someone at the device, and ask once, when it is needed.

**Why.** Repository rule since the bootstrap: a claim of a bench result nobody had is worse than an honest "unverified".

**How.**
- "Compiles clean; the reader path is unverified without the device" is a good report.
- If a step was skipped or a test failed, say so with the output.
