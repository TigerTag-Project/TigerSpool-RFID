# Roadmap

**Rule.** `docs/ROADMAP.md` holds what is deliberately not done, why, and what must be decided first. An item leaves it by being built or ruled out, never by rotting. Do not start an item that is blocked on a decision.

**Why.** Two entries are blocked on decisions (who owns each account field, who writes the change signal); building either without the answer produces something that has to be undone.

**How.**
- When work builds or rules out an item, remove or update it in the same commit.
